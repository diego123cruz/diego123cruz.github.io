# 🎮 Site Pessoal Retro - Diego Cruz

Um site pessoal estilo anos 90 com referências de eletrônica e seus projetos do GitHub.

## 📁 Arquivos Inclusos

- **index.html** - Página inicial com menu de navegação
- **projetos.html** - Lista de projetos do GitHub
- **transistores.html** - Tabela de transistores comuns
- **resistores.html** - Tabela de resistores com código de cores
- **awg.html** - Tabela AWG para fios e cabos

## 🚀 Como Usar

1. **Baixe todos os arquivos .html** para uma pasta no seu computador
2. **Abra o `index.html`** em qualquer navegador web
3. **Clique nos links** para navegar entre as páginas

## ✏️ Como Editar

O site é 100% HTML puro, muito simples de editar:

### Editar a Página Inicial (index.html)

Abra `index.html` em um editor de texto simples (Bloco de Notas, VS Code, etc) e procure por:

```html
<h1>DIEGO CRUZ</h1>
<p class="tagline">[ Z80 ENTHUSIAST & RETRO COMPUTING ]</p>
```

Altere o texto conforme desejar.

### Adicionar Novas Páginas

1. Copie qualquer arquivo `.html` como base
2. Edite o conteúdo
3. Adicione um link em `index.html`:

```html
<li><a href="sua_pagina.html">Seu Título</a></li>
```

## 🎨 Cores Utilizadas

- `background-color` - fundo
- `color` - texto
- `#00ff00` - verde
- `#ffff00` - amarelo
- etc.
